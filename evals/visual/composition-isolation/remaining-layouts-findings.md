# Remaining Layouts — Digital Media Gallery

## Test scope

This follow-up adds one availability proof for each remaining Composition Contract. The theme is `Digital Media Gallery`; the content structure changes where the layout requires it. `FRAME_THRESHOLD` and `RHYTHMIC_FIELD` use `SOCIAL_COVER` with three core strings, `IMAGE_MASK_FIELD` uses `PHOTO_COVER` with the supplied image, and `INFORMATION_AXIS` uses `EDITORIAL_POSTER` with seven controlled test strings. This is not a reliability study: each layout has one initial proof and zero retries.

## Observed evidence shared by all four

- All four proofs passed PNG, `1080 × 1440`, 3:4, opaque delivery checks.
- All four show a continuous full-bleed background across the corners and perimeter.
- All four keep `DIGITAL MEDIA GALLERY` as the first reading event at full size and approximately 25% thumbnail size.
- Each proof uses one dominant spatial relationship rather than a generic detached title/object split.
- Each proof retains one quieter release region and uses alignment as structure rather than decoration.

## Layout-specific observations and interpretation

### `FRAME_THRESHOLD`

Observed: One rounded arch contains a single period media device. The title enters from the left and the subtitle follows the lower threshold edge.

Interpretation: The entry direction survives detail removal and the frame reads as a threshold, not a floating UI card. The archive device's rectangular chassis contrasts clearly with the rounded boundary.

### `RHYTHMIC_FIELD`

Observed: Four matching spherical signal instruments follow one diagonal path. One lower-right instance is substantially larger; the title occupies an open upper band.

Interpretation: Repetition reads as one family because the silhouette, material, and signal-aperture language stay consistent while scale provides a primary instance. The open title band is essential; equal repeats would risk wallpaper behavior.

### `IMAGE_MASK_FIELD`

Observed: The supplied photograph remains recognizable. The woman's face, body, white floral dress, and dense green palm foliage are preserved; the title sits inside one pale curved low-detail cut at upper-left. Authentic sign lettering remains photographic intrinsic detail.

Interpretation: The proof demonstrates the intended mask behavior and identity preservation. It does not establish that every supplied image will survive the same transformation; image fidelity must be tested separately.

### `INFORMATION_AXIS`

Observed: A single vertical rule carries the category, deck, four controlled test-metadata strings, and footer. One archival media device attaches to the lower rule while the title spans the top.

Interpretation: Support copy becomes an information skeleton rather than scattered metadata. The copy is explicitly test metadata, not invented public event facts; a real public poster would require user- or source-supplied facts.

## Contract effect versus generator variance

- Contract effect: the frame boundary, repeated path, image mask, and information rule each changed the subject/copy relationship in the expected way.
- Generator variance: exact type weight, line breaks, archive-device details, atmospheric placement, and photographic grading varied between cases.
- The `IMAGE_MASK_FIELD` result includes an additional source-fidelity dependency because the supplied photograph must survive the transformation while remaining identifiable.
- No failure class repeated across at least two cases in this four-proof availability pass.

## Follow-up hypotheses

- `FRAME_THRESHOLD` may need extra caution when the subject already contains a strong aperture or canopy, because two openings can compete.
- `RHYTHMIC_FIELD` should be reliability-tested with at least two object families; its success depends on primary-instance scale contrast and the protected title band.
- `IMAGE_MASK_FIELD` needs repeated tests across portrait, scene, and low-contrast source images before preservation behavior is considered reliable.
- `INFORMATION_AXIS` needs public-content fixtures with real dates, locations, or classifications; controlled test metadata only proves the spatial behavior.

No exact wording changes to `SKILL.md` or the visual catalogs are proposed from this availability pass.
