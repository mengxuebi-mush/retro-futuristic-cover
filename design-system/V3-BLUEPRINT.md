# Retro Futuristic Cover — V3 Subject System Blueprint

V3 separates spatial composition, subject provenance, rendering, and scale. The current Composition Contract layer makes layout content-driven and resolves the subject only after the title zone and object slot are locked.

## Decision architecture

```text
carrier → information structure → Composition Contract → focal event + release zone
        → subject origin → object family or abstract form → render treatment → scale role
        → screen state when supported → palette + gradient topology → type mode → material + details
```

## Eight Composition Contracts

- `ASYMMETRIC_COUNTERWEIGHT`
- `CENTERED_ANCHOR`
- `FRAME_THRESHOLD`
- `PERSPECTIVE_VECTOR`
- `RHYTHMIC_FIELD`
- `TYPE_DOMINANT_FIELD`
- `IMAGE_MASK_FIELD`
- `INFORMATION_AXIS`

Each contract locks perceptual attention, title zone, replaceable object slot, collision, support-copy anchors, crop behavior, release area, failure signals, and thumbnail behavior. The subject adapts to this spatial contract; it does not select or reshape the layout.

## Three visual subject origins

- `ABSTRACT_FORM`: non-referential shapes and atmospheric structures. No fake product controls.
- `ARCHIVE_ARTIFACT`: recognizable real objects from the technological past. Preserve provenance, materials, proportions, and 2–4 identity anchors.
- `SPECULATIVE_OBJECT`: invented but apparently functional future devices. State one hypothetical function and preserve 2–4 purpose-bearing parts.

Supplied portraits, scenes, symbols, and objects use `SOURCE_ASSET_MODE`; this is an input-source override, not a fourth visual style.

## Independent treatments

- `FAITHFUL_RETAINED`: local color and materials remain identifiable.
- `ENVIRONMENT_GRADED`: global palette cast and print grain unify the surface without erasing identity.
- `PALETTE_ASSIMILATED`: body, light, shadow, haze, and gradient derive from active hues.

Archive artifacts never use `PALETTE_ASSIMILATED`.

## Independent scale roles

- `FIELD_STRUCTURE`
- `MONUMENTAL_FRAGMENT`
- `INTEGRATED_HERO`
- `CENTERPIECE_ARTIFACT`
- `SPECIMEN_ANCHOR`
- `REPEATED_FIELD`

Scale does not follow provenance. An archive computer may be monumental or tiny; a speculative device may be a centerpiece, integrated hero, specimen, or repeated family.

## Text behavior

- Social, photo, packaging, and record carriers use `THREE_ELEMENT_COVER`.
- Editorial posters use `EDITORIAL_POSTER_5_TO_7`: three core elements plus 2–4 factual support elements attached to real composition structure.
- `INTRINSIC_ARTIFACT_TEXT` is source-borne identity evidence, not designed copy. Preserve it when safe, faithful, and subordinate; never invent replacements.

## Conditional screen states

Screen behavior belongs to an explicitly screen-capable object family; it is not a universal technology effect.

- `DORMANT`: deep active-hue glass and reflection, with no generated content.
- `SIGNAL`: the default active state; one sparse nonverbal phosphor system and no readable screen text.
- `CARRIER`: editorial-poster-only; one exact locked support string moves into the screen, remains part of the 5–7 designed elements, and disappears from every external location.

Generated screen copy is never `INTRINSIC_ARTIFACT_TEXT`. In `REPEATED_FAMILY`, only the primary instance may be active.

## Catalog scope

The object catalog includes six speculative families and five archive families: computing, communication, media, mobility, and space technology. The selector, schema, compatibility rules, regression evals, and prose references consume the same V3 vocabulary.
